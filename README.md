# Nelsen Apps website

This is the public GitHub Pages website for Nelsen Apps and Hanami Sudoku.

## Publish
In repository Settings > Pages choose Deploy from a branch, main, /(root), and save.

Public addresses (after Pages is live):
- https://nelsenapps.github.io/
- https://nelsenapps.github.io/privacy/
- https://nelsenapps.github.io/support/
- https://nelsenapps.github.io/app-ads.txt

No custom build or GitHub Actions workflow is required.

## Before final app-store submission
- Approve a public support/privacy email and replace the temporary GitHub Issues-only contact mechanism on the support and privacy pages.
- Confirm the privacy text against the final Android and iOS releases, the AdMob/UMP data practices, intended target audience, and Google Play Data safety / Apple privacy declarations.
- Add an in-app privacy-policy link to Hanami Sudoku Settings.
- Verify that the exact authorized-sellers app-ads.txt entry shown by AdMob matches the root file.
- Update the homepage's Coming Soon label after the apps are available.
